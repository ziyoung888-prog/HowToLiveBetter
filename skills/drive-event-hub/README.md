# Drive Event Hub — implementation contract (not deployed)
Use Google changes.getStartPageToken, changes.watch and paginated changes.list. HTTPS receiver validates channel ID/token/resource ID; persist event before acknowledging. Notifications carry no file details. Durable queue and cursor; advance cursor only after jobs durably recorded. Scope filter by approved folder ancestry, include previously indexed IDs for removals; handle folder moves and descendants with bounded reconciliation. Ignore index output. Coalesce file changes for five minutes, idempotency by file ID and version/hash. Renew channel before 7-day expiration with overlap; periodic lightweight cursor reconciliation for missed notifications, no full AI scan. Store credentials and folder IDs only in private runtime configuration. Do not log contents or tokens. Worker uses approved extraction environment, private index upserts and bounded retries. No paid services without approval.
Acceptance: synthetic upload, edit, rename, duplicate, removal, out-of-scope, duplicate webhook, failure/retry, channel renewal and missed event recovery. Verify same link and source preservation. Requires independently authorized Google OAuth/service identity, HTTPS runtime, durable storage/queue, approved extraction model and private index. Existing chat connector is not transferable OAuth credential.
Cross-agent setup: each agent loads repository AGENTS.md and relevant SKILL.md at task start, configures private index location and individual authorized connector. Codex local clone/bootstrap and other agents must be tested separately.
