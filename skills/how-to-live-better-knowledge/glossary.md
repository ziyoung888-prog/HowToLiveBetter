# Glossary

## 证据等级 A / B / C
书内使用的证据标记。必须读取具体条目的来源和备注；A 不自动等于“所有人都适用”。

## 成本标签
正文条目可能用 HTML 注释记录钱、时间、毅力等成本维度。用于书内排序，不是自然科学意义上的统一效用函数。

## 收益口径
书把主要收益分开处理，例如寿命/健康、时间精力、金钱、人身自由。不同口径原则上不强行折算成一个总分。

## 性价比
作者基于自身规则做出的综合判断。它本身属于作者方法，不应与条目背后的研究证据等级混为一谈。

## 争议
正文明确指出存在反方证据、适用条件或结论不稳定。回答时必须把争议带上。

## TODO / 待核实
不能作为已确认结论使用。

## 政策时效
金额、资格、办理条件、签证、法律程序等可能随时间变化；使用时应保留正文日期并优先复核官方当前规则。

## 高风险条目
急症、自伤/他伤、刑事程序、药物、孕产、重大法律或财务事项。优先安全与专业边界，不做普通性价比排序。
