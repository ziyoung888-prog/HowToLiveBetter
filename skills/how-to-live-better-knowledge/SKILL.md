# HowToLiveBetter Knowledge Skill

## 定位

这是《高性价比人生指南》的**知识检索层**，不是新的个人决策器。

职责分工：
- `how-to-live-better-knowledge`：找章节、条目、原文、证据、适用条件与反例。
- `life-decision-guide`：用书中的条目回答“该不该、值不值、怎么选”。
- `personal-decision-guide`：再加入用户个人目标、约束、机会成本与长期路径。

## 核心原则

1. **原文优先**：章节文件只是路由，真正结论必须回到 `book/*.md` 的完整条目。
2. **整条读取**：标题、成本、收益、证据等级、来源、备注、争议和例外一起读。
3. **不凭记忆补数字**：原文没有的数字、法条、研究结论不要补。
4. **区分内容性质**：书中事实/研究结果、作者的性价比判断、政策信息、法律通用口径、个人推论必须分开。
5. **时间敏感内容要复核**：金额、政策、资格、法律程序、留学/签证等可能变化的信息，带上书中截至日期并在需要时查当前官方来源。
6. **高风险优先安全**：急症、人身安全、自伤/他伤、正在进行的法律程序，不先做普通“性价比”分析。

## 使用流程

### Step 1 — 定位主题

先看：
- `cheatsheet.md`：主题 → 章节快速映射；
- `chapters/`：每章路由文件；
- `patterns.md`：跨章节反复出现的方法。

通常先选 1–3 章，不要全书加载。

### Step 2 — 读取原始章节

根据章节路由打开对应的：

`book/<章节文件>.md`

先搜索条目标题，再读取完整条目。不要只凭章节路由文件回答具体数字或证据结论。

### Step 3 — 核验证据

对每个关键结论至少确认：
- 条目号与标题；
- 证据等级；
- 来源；
- 适用人群；
- 备注/争议/例外；
- 是否有政策日期或 TODO。

需要时联用 `evidence-verification`。

### Step 4 — 输出

知识型查询优先给：
1. 明确判断；
2. 相关条目；
3. 原文支持的核心结论；
4. 证据等级与来源；
5. 适用条件/反例；
6. 书中没有覆盖的部分。

引用格式：
`第 X 节第 Y 条（条目标题）`

## 什么时候不要单独使用本 Skill

- 用户问“我该不该做”：转 `life-decision-guide` 或 `personal-decision-guide`。
- 用户给出个人病情/案件/投资组合：不能只靠本书作个性化专业判断。
- 用户问当前政策金额、签证规则、法规现状：本书只做线索，需再查官方当前信息。
