# Skills Library

本目录按“能力”组织，而不是按书名组织。

原则：
- 书、标准、项目经验都是原料；
- 同一个 Skill 可以被多本书和真实案例共同强化；
- 不因为读完一本书就创建一个 Skill；
- 新 Skill 必须解决重复出现、可执行、可验证的任务。
